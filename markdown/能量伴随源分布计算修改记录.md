## 修改记录

### 一、总体目标

在 β_eff 计算流程中引入 **能量分辨源状态**（source_state = source_cell × n_source_groups + g_source），使裂变矩阵幂迭代和格林函数传递函数均在源能群维度上展开，从而提高伴随通量卷积精度。

---

### 二、各文件修改明细

#### 1. fission_matrix.h

| 类别 | 修改内容 |
|------|---------|
| 构造函数 | 新增 `std::vector<double> energy_edges = {}` 参数，用于初始化源能群边界 |
| `record_source_birth` | 新增 `double energy = -1.0, int mg_group = -1` 参数 |
| 公开访问器 | 新增 `get_adjoint_source_grouped()`, `n_source_groups()`, `source_energy_edges()`, `state_to_cell()`, `state_to_group()`, `cell_group_to_state()` |
| 私有成员 | `source_birth_cells_` → `source_birth_states_`；新增 `n_source_groups_`, `source_energy_edges_`, `adjoint_source_grouped_` |
| 辅助函数 | 新增私有方法 `determine_source_group(double, int) const` |

#### 2. greenfunction_mesh.h

| 类别 | 修改内容 |
|------|---------|
| `record_source_birth` | 新增 `double energy = -1.0, int mg_group = -1` 参数 |
| 内部映射 | `particle_to_source_cell_` → `particle_to_source_state_`（外层 key = source_state） |
| 传递函数存储 | `transfer_functions_sparse_` 外层 key 由 source_cell 改为 source_state |
| 新访问器 | `int n_source_groups() const { return n_groups_; }` |

#### 3. adjoint_flux.h

| 类别 | 修改内容 |
|------|---------|
| `compute_from_memory` | 新增 `int n_source_groups = 1` 参数 |

#### 4. simulation.cpp

| 类别 | 修改内容 |
|------|---------|
| FissionMatrix 初始化 | 传入 `settings::kinetics_energy_edges` 作为第三参数，启用源能群支持 |

#### 5. particle.cpp

| 类别 | 修改内容 |
|------|---------|
| `from_source` | `record_source_birth` 调用分 CE/MG 两路：CE 传 `src->E`，MG 传 `static_cast<int>(src->E)`；对 `transfer_function_mesh` 同理 |

#### 6. fission_matrix.cpp

| 类别 | 修改内容 |
|------|---------|
| 构造函数 | 处理 energy_edges，计算 `n_source_groups_`；向量尺寸扩展为 `n_source_states = n_cells × n_source_groups` |
| `record_source_birth` | 调用 `determine_source_group()`，计算 `source_state = cell * n_source_groups_ + g`，存入 `source_birth_states_` |
| `record_fission_event` | 矩阵行 key 改为 source_state（原为 source_cell） |
| `start_new_batch` | 累积 source_state 索引的 counts，清空 `source_birth_states_` |
| `compute_adjoint_source` | **完全重写**：预计算经验 χ（`χ(g|j) = source_counts[j*n+g] / Σ_g source_counts`），构建按 source_state 索引的归一化矩阵，运行能量分辨幂迭代，折叠得到标量`adjoint_source_` 保持后向兼容 |
| `perform_adjoint_iteration` | **完全重写**：与 `compute_adjoint_source` 相同的能量分辨逻辑 |
| `finalize` | 输出 `n_source_groups`, `source_energy_edges`, `adjoint_source_grouped`（新增）；row_dim = n_source_states；版本号 → **3.0** |
| `determine_source_group` | **新增函数**：CE 模式用二分查找能量区间，MG 模式直接用整数索引 |

#### 7. greenfunction_mesh.cpp

| 类别 | 修改内容 |
|------|---------|
| `record_source_birth` | 接受 energy/mg_group，调用 `determine_group()`，计算 source_state，存入 `particle_to_source_state_` |
| `accumulate` | 使用 `particle_to_source_state_` 替代旧的 `particle_to_source_cell_` |
| `start_new_batch` | 清空 `particle_to_source_state_`（修复内存泄漏） |
| `finalize_greenfunction_mesh` | 写出 `source_state_indices`, `source_state_cell`, `source_state_group` 解码元数据；传递函数分组命名改为 `source_state_N`；每组含 `source_cell` + `source_group` 属性；写出 `n_source_groups`；版本号 → **5.0** |

#### 8. adjoint_flux.cpp

| 类别 | 修改内容 |
|------|---------|
| `compute_from_files` | 读取 TF 文件 `n_source_groups` 属性；优先用 `source_state_indices`（回退 `source_cell_indices`）；传递函数组名前缀改为 `source_state_*`；优先读取 FM 文件 `adjoint_source_grouped`，否则读标量 `adjoint_source`；将 `effective_n_source_groups` 传给 `compute_from_memory` |
| `compute_from_memory` | 新增 `int n_source_groups = 1` 参数；验证 `adjoint_source.size() == n_cells * n_source_groups`；卷积循环 key 即为 source_state，`importance = adjoint_source[i_source]` 标量路径/分群路径均可 |
| `write_to_file` (semantic_metadata) | 更新物理描述：反映 source_state 卷积公式 `Φ†(r) = Σ_{cell,g} T(cell,g→r) × I*(cell,g)` |

### 三、HDF5 文件格式变更

| 文件 | 版本 | 新增字段 |
|------|------|---------|
| fission_matrix.h5 | 3.0 | `n_source_groups`, `source_energy_edges`, `adjoint_source_grouped`（size = n_cells × n_source_groups） |
| transfer_function_data.h5 | 5.0 | `source_state_indices`, `source_state_cell`, `source_state_group`, `n_source_groups`；分组命名 `source_state_N`（替代 `source_cell_N`） |

### 四、后向兼容性

- 当 `settings::kinetics_energy_edges` 为空（或只有1群）时，`n_source_groups_ = 1`，`source_state = source_cell`，所有新路径退化为旧路径，结果完全等价。
- `adjoint_flux.cpp` 读取旧格式文件时可回退使用 `source_cell_indices` 和标量 `adjoint_source`。

已进行更改。
