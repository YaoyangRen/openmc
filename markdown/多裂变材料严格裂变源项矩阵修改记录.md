# 多裂变材料严格裂变源项矩阵修改记录

日期：2026-06-02

## 1. 修改目标

本次修改将 beta_eff 主计算路径从“材料等效核数据”方案切换为“严格裂变源项矩阵”方案。原程序虽然能够通过几何查询识别多个可裂变材料，但 beta_eff 主公式仍主要依赖材料级等效量：

```text
Sigma_f(g) * nu(g) * chi(g_birth)
```

对于 U235、U238、Pu239 等多裂变核素或多裂变材料体系，这种先平均 `sigma_f / nu / chi` 再计算 beta_eff 的方法会丢失核素、入射能群、出生能群和迟发组之间的耦合关系。

修改后，程序直接构造并使用裂变源项矩阵：

```text
P_prompt(g_in, g_birth)
P_delayed(g_in, delayed_group, g_birth)
```

beta_eff 主计算不再通过材料平均的 `(nu_delayed / nu_total)` 近似分配迟发组贡献；迟发组份额改为由严格源项矩阵反推。由于当前 `fission_matrix.h5` 给出的 `I*(cell,g_birth)` 是 fission source-state importance，而不是真正可区分 prompt/delayed 谱族的输运伴随重要性，因此分子不能直接用 `P_delayed * I*`。正确做法是先用 `I*` 折叠总出生源，再按严格 delayed 源项份额分配各迟发组。

## 2. 新增数据结构

修改文件：

- `include/openmc/material_nuclear_data.h`

新增统一索引函数：

```cpp
prompt_source_offset(n_energy_groups, incident_group, birth_group)
delayed_source_offset(n_energy_groups, incident_group, delayed_group, birth_group)
```

新增 `MaterialNuclearData` 字段：

```cpp
std::vector<double> prompt_prod_groups;
std::vector<double> delayed_prod_groups;
double fissionable_volume_fraction;
```

索引规则为：

```text
prompt_prod_groups:
  index = g_in * G + g_birth

delayed_prod_groups:
  index = (g_in * 8 + delayed_group) * G + g_birth
```

其中 `G` 为能群数，迟发中子组数仍采用当前程序中的 8 组。

## 3. 材料核数据提取修改

修改文件：

- `src/material_nuclear_data.cpp`

新增函数：

```cpp
MaterialNuclearDataExtractor::compute_fission_source_terms(...)
MaterialNuclearDataExtractor::sample_nuclide_spectrum_matrices(...)
MaterialNuclearDataExtractor::representative_incident_energy(...)
derive_diagnostic_nuclear_data_from_source_terms(...)
```

材料核数据提取流程修改为：

1. 读取材料中的全部可裂变核素。
2. 对每个可裂变核素计算多群微观裂变截面 `sigma_f,i(g_in)`。
3. 对每个可裂变核素计算 `nu_prompt,i(g_in)` 和 `nu_delayed,i,d(g_in)`。
4. 按入射能群采样 prompt/delayed 出生谱，得到 `chi_i(g_in -> g_birth)`。
5. 直接累加宏观裂变源项矩阵。

源项矩阵定义为：

```text
P_prompt(g_in, g_birth)
  = sum_i N_i * sigma_f,i(g_in) * nu_prompt,i(g_in)
          * chi_prompt,i(g_in -> g_birth)

P_delayed(g_in, d, g_birth)
  = sum_i N_i * sigma_f,i(g_in) * nu_delayed,i,d(g_in)
          * chi_delayed,i,d(g_in -> g_birth)
```

其中：

- `i` 为材料中的可裂变核素；
- `N_i` 为核素原子密度；
- `g_in` 为入射中子能群；
- `g_birth` 为裂变出生中子能群；
- `d` 为迟发中子组。

旧的 `sigma_f_groups / nu_* / chi_*` 字段不再作为 beta_eff 主计算依据，而是由严格源项矩阵反推生成，仅用于诊断和兼容输出。

## 4. beta_eff 主公式修改

修改文件：

- `src/beta_effective.cpp`
- `include/openmc/beta_effective.h`

主分母改为：

```text
D = sum_c dV sum_gin sum_gbirth phi(c, gin) I*(c, gbirth)
    [P_prompt(c, gin, gbirth)
     + sum_d P_delayed(c, gin, d, gbirth)]
```

定义严格 delayed 源项份额：

```text
f_d(c, gin)
  = sum_gbirth P_delayed(c, gin, d, gbirth)
    / sum_gbirth [
        P_prompt(c, gin, gbirth)
        + sum_j P_delayed(c, gin, j, gbirth)
      ]
```

第 `d` 个迟发组分子改为：

```text
N_d = sum_c dV sum_gin f_d(c, gin)
      sum_gbirth phi(c, gin) I*(c, gbirth)
      [P_prompt(c, gin, gbirth)
       + sum_j P_delayed(c, gin, j, gbirth)]
```

最终：

```text
beta_d = N_d / D
beta_eff = sum_d beta_d
```

因此，主链路中已经移除以下旧近似：

```text
(material-averaged nu_delayed,d / material-averaged nu_total) * W_total
```

但仍保留“总出生源 importance 折叠后分配 delayed 组”的结构，因为这是当前 `fission_matrix.h5/adjoint_source_grouped` 所能支持的物理含义。

## 5. 多材料 cell 混合修改

修改文件：

- `src/beta_effective.cpp`

原逻辑在网格 cell 内采样到裂变材料后，若只有一种裂变材料，会直接使用该材料核数据；若还有慢化剂、空隙或几何失败点，这会导致裂变源强度被错误归一化为纯燃料。

修改后：

```text
P_cell = sum_m f_m * P_material,m
```

其中 `f_m` 使用该网格 cell 的总采样点数作为分母：

```text
f_m = material_hits_m / total_sample_points
```

这意味着：

- 多种裂变材料会按几何体积分数混合；
- 裂变材料与慢化剂混合时，非裂变体积分数会真实稀释裂变源；
- 不再使用只按裂变材料命中数归一化的做法。

若某个可裂变材料缺少核数据缓存，程序现在会直接报错，避免静默少算材料贡献。

## 6. Method E 统一

修改文件：

- `src/beta_effective.cpp`

Method E 中使用的总裂变源强 `F_total(g)` 也改为从严格源项矩阵求和得到：

```text
F_total(g_in)
  = phi(g_in) * sum_gbirth [
      P_prompt(g_in, gbirth)
      + sum_d P_delayed(g_in, d, gbirth)
    ]
```

这样主方法和 Method E 使用同一套裂变源项定义，避免一个路径使用矩阵、另一个路径仍使用 `sigma_f * nu_total` 的不一致。

## 8. 误差修正记录

直接使用：

```text
N_d = sum phi * I*(g_birth) * P_delayed(d, g_birth)
```

会把 delayed 出生谱单独乘以 `fission_matrix.h5` 的 source-state importance。该 importance 当前不是 prompt/delayed family-resolved 的输运伴随场，因此这种做法会过度惩罚 delayed 谱，导致 beta_eff 从约 `6.2e-3` 下降到约 `1.1e-3`。

HDF5 诊断显示：

```text
material_prompt_source_total  = 122.888
material_delayed_source_total = 0.802025
source delayed fraction       = 0.802025 / (122.888 + 0.802025)
                              ~= 0.00648
```

该源项份额与 MCNP 参考 `0.00621` 同量级，说明核数据源项矩阵本身没有少算；误差来自 delayed 谱 importance 的使用方式。修正后分子使用严格 delayed 源项份额 `f_d(c,gin)` 乘以总出生源折叠重要性。

## 11. 后续建议

建议增加一个小规模验证算例：

```text
particles = 100
batches = 20
inactive = 5
```

并至少覆盖以下情形：

1. 单 U235 材料，确认与旧结果在统计误差内一致；
2. 同一材料中包含 U235 和 Pu239，确认源项矩阵为两种核素贡献之和；
3. 一个网格 cell 中同时存在裂变材料和慢化剂，确认裂变源项按燃料体积分数降低；
4. 两种裂变材料位于同一网格 cell 内，确认 `P_cell` 按采样体积分数线性混合；
5. 检查 `beta_eff.h5` 中 `material_prompt_source_total` 和 `material_delayed_source_total` 是否包含所有裂变材料贡献。
